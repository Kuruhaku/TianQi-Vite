# Tianqi-Saito

A Weather and News website that utilize API and developed inside HTML, CSS and JavaScript. This website accept users input and return weather and news information base on the value given by the users.

## Before running the website:

1. Install luxon.js (Handle date and time for different time zone)

```
npm install luxon
```

```
npm install full-icu
```

2. Install particle.js (Particle for rain and snow weather condition)

```
npm i particles.js
```
